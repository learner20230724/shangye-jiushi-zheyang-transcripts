## 怎么阅读与打印

1. 打开[单集目录](EPISODES.md)，按节目标题找到所需单集；也可用页面内搜索查关键词。
2. 快速阅读选“校读TXT”；需要打印选“Word”，进入文件页后下载，使用 Word 或 WPS 打开。
3. “原始TXT”是机器转写稿，未完成校读时可能没有合适的标点与分段，不应当成最终读稿。

## 单集文件结构

```text
商业就是这样/
└── 单集节目名称/
    ├── 全文_原始转写.txt
    ├── 全文_校读版.txt
    └── 全文_校读版.docx
```

Word 标题使用宋体；标题下只保留节目时长和来源，之后直接开始正文。正文保留口语、重复表达与限定条件，按自然段整理；每20分钟在附近自然段前设置一处时间索引，供近似定位。

## 校读范围与纠错

文稿来自自动语音识别，并在已完成的校读版中由模型逐段整理标点、自然段和有证据的识别错误。模型文字校读不等于真人逐字核音，也不保证音频每句话都已正确识别。疑词、疑似缺口按实际情况保留标记；原始稿同时保留供比较。

如发现错误，可在本仓库提交 Issue，注明单集、文稿段落或时间位置以及建议订正。不要提交私人资料或未经授权的音频。
